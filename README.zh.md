# unirtos-spi-demos

中文 | [English](README.md)

## 概述

unirtos-spi-demos 用于展示 UniRTOS 下 SPI（Serial Peripheral Interface）能力的整体方案。
该目录聚焦 SPI 通信相关示例，覆盖从接口初始化到数据收发验证的典型场景，便于快速理解 SPI 能力边界与应用选型方向。
