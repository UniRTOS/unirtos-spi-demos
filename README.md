# unirtos-spi-demos

[中文](README.zh.md) | English

## Overview

unirtos-spi-demos provides an overall demonstration of SPI (Serial Peripheral Interface) capabilities on UniRTOS.
This directory focuses on SPI communication examples, covering typical scenarios from interface initialization to data transfer verification, so you can quickly understand SPI capability boundaries and solution selection direction.
